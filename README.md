# 💼 Job Tracker

A modern and responsive **Job Tracker** built with **React** and **Tailwind CSS** to help users manage and organize their job applications efficiently. It allows users to track application progress, manage resumes, and keep all job-related information in one place.

---

## 🚀 Features

- 📊 Dashboard with application statistics
- ➕ Add new job applications
- ✏️ Edit existing applications
- ❌ Delete applications
- 🔍 Search applications
- 🎯 Filter applications by status
- 📄 Resume Manager
- 💾 Data persistence using LocalStorage
- 📱 Fully Responsive UI

---

## 🛠️ Tech Stack

- React
- React Router DOM
- Tailwind CSS
- JavaScript (ES6+)
- Vite
- LocalStorage

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/job-tracker.git
```

Go to the project directory

```bash
cd job-tracker
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
