# Job Tracker

A modern React application to help users manage their job search in one place.

## 🚀 Features

- Dashboard with job overview
- Track job applications
- Add, edit, and delete applications
- Organize multiple resumes
- Search, filter, and sort applications
- Responsive user interface

## 🛠️ Tech Stack

- React
- React Router
- CSS
- Local Storage
